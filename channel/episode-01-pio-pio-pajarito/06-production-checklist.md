# Production checklist — Episode 1

## 1. Preparation
- [ ] Reference images ready: official image and day image (`../shared/references/`), Rosa's sheet
- [ ] Opening and closing music generated (done only once)
- [ ] Read the script out loud and time it (≈ 4:00)

## 2. Audio
- [ ] Generate the voices in ElevenLabs with `08-voices.md` (one box = one audio): Oryx, Luna and Rosa, scene by scene
      (write "Oris" in the voice text so the AI says the name correctly)
- [ ] Generate the song "Pío, pío, pajarito" (`02-song.md`)
- [ ] Sound effects: "beep-beep-beep", "RAWR", "woof", Luna's bell, birds chirping, park ambience

## 3. Video
- [ ] Generate the clips for each shot (`07-kling-shots.md`)
- [ ] Check that Oryx and Luna look the same in every clip; redo the ones that don't
- [ ] Check that the baby bird is always gray
- [ ] Check that Rosa is always the veterinarian (white coat, blue gloves) and has no weapon
- [ ] Check that no clip has text or subtitles drawn inside it

## 4. Editing
- [ ] Put the clips in order with the voices and the song
- [ ] 3-second pause in Scene 5 with the question mark
- [ ] Song lyrics on screen (big, round letters)
- [ ] Volume: voices clearly above the music; no sudden loud sounds
- [ ] Export at 1920×1080 (horizontal)

## 5. Extra pieces
- [ ] Separate music video with lyrics (1:00–1:15)
- [ ] Vertical Short, 1080×1920, 20–30 s with the chorus
- [ ] Thumbnail (`03-title-and-thumbnail.md`) at 1280×720

## 6. Upload
- [ ] Title, description and tags (`03` and `04`)
- [ ] Mark as **Made for Kids**
- [ ] Spanish subtitles
- [ ] Add to the "Oryx y Luna — Episodios" playlist
