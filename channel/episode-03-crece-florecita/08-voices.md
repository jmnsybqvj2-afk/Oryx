# Episode 3 · The Sad Little Flower — Voices for ElevenLabs

Each box is one line of dialogue. Copy the text of the box into ElevenLabs with **that character's voice**
and save the audio with the name shown (for example `T1-oryx-1.mp3`).

The name is written **"Oris"** inside the boxes so the voice pronounces it correctly.
Use these audios for Kling's Lip Sync or put them on top of the clip in CapCut.
