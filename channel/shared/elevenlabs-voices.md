# Creating the character voices in ElevenLabs

Create each voice **once**, save it, and always use the same one in every episode.

## How
1. In ElevenLabs, open **Voices → Create a voice → Voice Design** (design a voice from a description).
2. Paste the description of the character (below) and generate.
3. Listen to the options, choose the one you like best and **save it** with the character's name.
4. Then go to **Text to Speech**, choose the saved voice, paste each line from `08-voices.md`
   of the episode and download the audio with the file name shown there.

Tip: the free plan has a monthly character limit. Episode 1's dialogue is short, so generate each
line once and only regenerate the ones that sound wrong.

## Voice descriptions (paste in Voice Design)

A cheerful young boy, around 5 years old, speaking Latin American Spanish. Curious, amazed and
